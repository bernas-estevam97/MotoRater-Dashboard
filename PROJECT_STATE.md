## 1. Project Overview & Architecture

MotoRater Dashboard is a Streamlit-based suite designed for the visualization, analysis, and longitudinal modeling of experimental locomotion data generated by the MotoRater apparatus.

The codebase now operates in a unified **dual-mode architecture**:
1. **Streamlit Cloud Deployment:** A cloud-hosted environment (running headless on Linux) launched via `main.py` and `st.navigation`, with automatic headless detection that defaults to standard browser-based file uploaders (`st.file_uploader`).
2. **Local Standalone Deployment:** A portable or venv-based setup for workstations on Windows and macOS, launched via automated batch scripts (`Launch_Dashboard.bat`, `Update_Launch_App.bat`, `Launch_Dashboard.command`) with smart environment detection (utilizing existing `venv\` or portable `python_env\`), native desktop folder picking, and full dependency verification.

## 3. Improvements Applied

### A. Dependency Synchronization
* Added missing runtime dependencies to `requirements.txt`: `polars`, `streamlit-javascript`, `psutil`, `joblib`, `tables`, `pyarrow`, `kaleido`.
* Clean installations now have all necessary libraries for fast Polars aggregations, GEE/LMM models, and parallel plot exports.

### B. Headless & Cloud Safe Architecture
* Created `scripts/utils/file_utils.py` to detect whether Tkinter / display servers are present.
* Both `time_series_analysis_excel.py` and `time_series_analysis_parquet.py` now support dual-mode:
  - **Local Folder Mode:** Browse directories directly on desktop workstations.
  - **Upload Files Mode:** Drag-and-drop or upload directly via browser on Streamlit Cloud or local computers.
* Headless environments automatically fall back to browser upload without triggering `TclError`.

### C. Streamlit Multi-Page Warnings Resolved
* Safely guarded `st.set_page_config()` calls across `stat_info.py`, `convert_to_parquet.py`, and `kinematic_analysis_optimized.py`.
* Pages now integrate seamlessly with `st.navigation` in `main.py` with zero API exceptions.

### D. Centralized Data Mappings
* Created `scripts/utils/data_mappings.py` to establish a single source of truth for the 37 normalized sensor/kinematic measurement column names and scientific p-value formatting.
* Avoided 70KB of code drift by proxying `kinematic_analysis.py` directly to `kinematic_analysis_optimized.py`.

### E. Upgraded Batch & Shell Launchers
* `Launch_Dashboard.bat` & `Update_Launch_App.bat`:
  - Added smart detection for existing virtual environments (`venv\Scripts\python.exe`). If already installed, it boots instantly without downloading or reinstalling anything.
  - Portable Python setup now installs the full dependency suite and runs self-tests.
* `Launch_Dashboard.command`:
  - Updated macOS launcher to detect `venv` and install the complete dependency set from `requirements.txt`.

### F. Modernized Pandas Operations
* Replaced deprecated `pd.to_numeric(..., errors='ignore')` in `convert_to_parquet.py` with a safe numeric conversion handler.
