# 🐁 MotoRater Suite

An advanced, high-performance [Streamlit](https://streamlit.io/) application designed for the visualization, exploration, and longitudinal statistical modeling of locomotion and kinematic data generated by the **MotoRater** apparatus.

All data processing pipelines, experimental filtering algorithms, and statistical decision engines are developed and maintained by **Bernardo Estevam**.

---

## 🌟 Suite Overview & Capabilities

The MotoRater Suite provides an integrated research platform with tools tailored for both rapid exploratory checks and publication-grade statistical analysis:

| Tool | Format | Purpose | Key Capabilities |
| :--- | :--- | :--- | :--- |
| **📈 Time-Series Analysis (Excel)** | `.xlsx`, `.xls` | Exploratory time-series visualization from Excel files | Single & multi-file comparison, rolling-average noise filtering, polar angle plots, descriptive statistics, and correlation heatmaps. |
| **📈 Time-Series Analysis (Parquet / HDF5)** | `.parquet`, `.h5`, `.hdf5` | High-speed time-series analysis for large datasets | **Up to 50x faster loading** than Excel, low RAM footprint, multi-dataset inspection. |
| **📊 Kinematics Longitudinal Analyzer** | `.xlsx`, `.parquet`, `.h5`, `.zip` | Comprehensive longitudinal & cross-sectional modeling | Automated statistical routing (ANOVA, LMM, GEE), FDR/Holm multiple-testing corrections, parallel plot rendering, and radar profiling. |
| **⚡ Excel ➔ Parquet/HDF5 Converter** | `.xlsx` ➔ `.parquet` / `.h5` | Batch file converter & compressor | Converts multi-sheet Excel files into optimized Parquet tables (or HDF5 stores) with automated kinematics data cleaning. |
| **🧮 Statistical Methodology** | In-app Guide | Statistical reference & paper writing guide | Detailed breakdown of assumptions, normality tests, sphericity corrections, and copy-paste methods templates for scientific papers. |

## 🚀 Dual-Mode Operation: Cloud & Standalone

MotoRater Suite is designed to operate seamlessly across two deployment modes without code divergence:

1. **☁️ Streamlit Cloud (Web Browser)**
   * **Zero Installation:** Open the web application directly in any browser.
   * **Safe Headless Mode:** Automatically detects cloud environments and provides drag-and-drop file uploaders (`st.file_uploader`), completely avoiding desktop GUI crashes.
2. **💻 Local Standalone Workstation (Windows & macOS)**
   * **One-Click Launch:** Double-click automated launcher scripts that detect or configure your Python environment automatically.
   * **Direct Folder Access:** Pick local folders via native OS file dialogs or type paths directly.
   * **Full Offline Performance:** Process gigabytes of kinematic trials locally with multi-core parallel rendering.

## 🛠️ Quick Start & Installation

### Option A: Windows Automated Launchers (Recommended)
Place the repository folder onto your local machine (e.g., in `Documents` or `Desktop`) and run:
* **`Launch_Dashboard.bat` (First Run & General Launch)**
  * Automatically detects if a virtual environment (`venv`) already exists.
  * If no environment is found, automatically installs an isolated, portable Python 3.12 environment, verifies all dependencies, and launches the app.
* **`Update_Launch_App.bat` (Daily Use)**
  * Offers an optional 4-second prompt to check GitHub for the latest updates before launching the application.
* **`Updater.bat` (Standalone Background Updater)**
  * Fetches and applies the latest updates from GitHub without starting the application.

### Option B: macOS Automated Launcher
* Open Terminal, ensure execution permissions are granted:
  ```bash
  chmod +x Launch_Dashboard.command
  ```
* Double-click **`Launch_Dashboard.command`** to create the virtual environment, install dependencies, and launch the suite.

### Option C: Manual Installation (Developer / Power Users)
```bash
# 1. Clone or download repository
git clone https://github.com/bernas-estevam97/MotoRater-Dashboard.git
cd MotoRater-Dashboard

# 2. Create and activate virtual environment
python -m venv venv
# On Windows:
venv\Scripts\activate
# On macOS / Linux:
source venv/bin/activate

# 3. Install dependencies
pip install -r requirements.txt

# 4. Launch the application
streamlit run main.py
```

## ⚡ Performance Tips: Why Does First Load Take a Moment?

### 1. Cold-Start Imports & Background Pre-Warming
* **Why it happens:** Heavy scientific packages (`pingouin`, `statsmodels`, `scipy`, `openpyxl`) require 5–10 seconds on the very first execution of a fresh Python process to compile and index into memory.
* **Built-in Optimization:** The suite includes an automatic background **Pre-Warmer** in `main.py`. While you view the Welcome landing page, heavy modules are silently loaded into memory so that navigating to the Kinematics or Time-Series tools is fast and responsive.

### 2. Excel vs. Parquet Speed Difference
* Raw `.xlsx` files are zipped XML documents that require significant CPU time to decompress and parse.
* **Tip:** For large experimental datasets, run your Excel files through the **⚡ Excel ➔ Parquet Converter** once. Parquet files load in **~0.05 seconds** (50x faster) and use a fraction of system RAM.

### 3. Freeing Memory
* When comparing dozens of high-frequency locomotion trials, click the **`🧹 Clear Server Cache`** button in the sidebar to release RAM and purge stale DataFrames from cache.

## 🧮 Statistical Decision Tree

When analyzing longitudinal data in the **Kinematics Longitudinal Analyzer**, the suite applies an automated statistical pipeline:
* **Single Timepoint (Cross-Sectional):**
  * Evaluates residual normality via the Shapiro-Wilk test.
  * **Parametric:** Welch's Independent t-test (robust to unequal variances).
  * **Non-Parametric:** Mann-Whitney U test.
* **Two or More Timepoints (Longitudinal):**
  * **Pipeline A (2-Way Mixed ANOVA):** Triggered when data is normally distributed and perfectly balanced. Applies Mauchly's sphericity test with Greenhouse-Geisser correction (`p-GG-corr`).
  * **Pipeline B (Linear Mixed-Effects Models - LMM):** Triggered when data is normal but has missing timepoints or dropouts, preventing Survivor Bias without dropping animals.
  * **Pipeline C (Generalized Estimating Equations - GEE):** Triggered when normality assumptions are violated (skewed data). Uses robust Sandwich estimators and Wald contrast tests.
* **Multiple Comparisons:** All post-hoc p-values are adjusted using the **Holm-Bonferroni** or **FDR (Benjamini-Hochberg)** step-down methods.
