### MotoRater Dashboard

- This is a streamlit dashboard to analyze all the data from the MotoRater apparatus. The data obtained from measurement algorithms are obtained and filtered by &copy; Bernardo Estevam.
- For more information on the filtering algorithms for the case of our lab experiments and setup, contact me at <bernaz.estevam97@gmail.com>


##### Batch files tutorial

- There are 3 different batch files in this repository:
    1. Launch_Dashboard.bat --> You can simply run this bat file alone to a folder of your choice. It will install python embedded version 3.12 along with all the dependencies of the app. If all checks out it will finally launch the application for you to use
    2. Update_Launch_App.bat --> For later usages and if the user wants to check for updates and update the app on new runs. This will simply ask the user on click if he wants to update the app or not and will launch the app afterwards with either user choice
    3. Updater.bat --> This is a simple updater of the app. If the user simply wants to update the app but not run it this is a possibility with this batch script.
