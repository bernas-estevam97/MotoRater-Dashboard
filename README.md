MotoRater Dashboard
A Streamlit-based dashboard designed for the visualization and analysis of data generated by the MotoRater apparatus.

All data processing, including the measurement and filtering algorithms specific to our laboratory setup and experiments, are developed and maintained by Bernardo Estevam.

🚀 Quick Start & Installation
To ensure a seamless setup experience across different Windows machines, this repository includes automated batch scripts. These scripts handle the installation of a portable Python 3.12 environment, manage all necessary dependencies, and keep the application up to date.

Place the downloaded files into a dedicated folder of your choice and use one of the following scripts:

Launch_Dashboard.bat (Recommended for First Run)

Purpose: Automated standalone setup and execution.

Behavior: Installs an embedded version of Python 3.12, downloads all required app dependencies, and immediately launches the Streamlit dashboard.

Update_Launch_App.bat (Recommended for Daily Use)

Purpose: Standard launcher with version control.

Behavior: Prompts the user to check for the latest remote updates before launching. Regardless of whether the user chooses to update or skip, the application will launch immediately afterward.

Updater.bat

Purpose: Standalone background updater.

Behavior: Fetches and applies the latest updates from the repository without launching the application. Ideal for updating the tool quickly in the background.

🌿 Branching Strategy & Releases
Development (dev branch): The most recent updates, advanced features, and ongoing algorithm adjustments are maintained in the dev branch. Users looking for the latest capabilities should pull from here. The updates are currently being fetched from this branch.

Stable Releases: For users who prefer a manual installation rather than using the automated batch scripts, packaged source code is available in the Releases section of this repository.
